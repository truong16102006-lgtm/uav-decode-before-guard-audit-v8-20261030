## Wire and escape

Use a new versioned wire, preserving v7 strict UEC1/UEV1 as references. Header remains 36 bytes: magic, binary64 origin, h, power and energy quantum. Packet normal fields are type:uint8, sequence:uint16 modulo 65536, absolute tick:ULEB64, nonnegative power-count:ULEB64 and cumulative energy-count:ULEB64. A packet's byte cost depends on its endpoint, not its ordinal, because the sequence field has constant width. Decode every proposed packet before guards.

An escape endpoint has its own type flag, modulo sequence, tick, binary64 endpoint power and binary64 cumulative energy. It anchors to the already emitted decoded start, uses nonnegative raw adjacent endpoint power and the linear integral from that actual start; it is NOT a retroactive replacement of a transmitted start. It must pass the same applicable continuous guards, and shared decoded power/energy endpoints preserve continuity. If even this adjacent escape fails, retain a real record refusal and its first/all failed guards. Escape is not assumed universally feasible outside declared finite positive uniform-tick inputs. Strict, rounding-only, escape-only and rounding+escape are separate modes.

Candidate search fixes Ti and considers the union of floor, ceil, nearest and nearest±1 for Pi and Ai, removing negative/out-of-range counts. Select the cheapest actual passing packet with deterministic ties by maximum energy error, power error, distance from unrounded values, then count order. Already transmitted starts never change. Compare rescued and harmed records, bytes and CPU; search is not a global path optimizer.

Footer: a one-byte end tag alone cannot identify an erased terminal checkpoint. Include final modulo sequence and absolute tick as framing metadata and count every byte. Delivered footer plus its expected endpoint can expose terminal erasure; an erased footer leaves the stream ending unknown. CRC32 optionally adds four bytes, detects accidental errors and is not authentication.

Modulo unwrap uses tick-gap bounds and the five-second/ten-interval edge cap: for delta tick T, number of original edges K lies in [ceil(T/10),T], with K congruent to the sequence difference modulo 65536. Certify adjacency only if uniquely resolved; multiple candidates are marked ambiguous rather than invented. Ordered delivered packets and a received header are explicit transport assumptions.
